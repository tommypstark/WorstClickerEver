# Worst Clicker Ever 🎮

A simple Android clicker game built with Kotlin and Jetpack Compose.

This is a personal learning project focused on understanding Android development and building a
complete game from scratch.

## Features – Version 1.0

- A simple button that gives +1 point per click.
- A score counter that updates instantly.
- A minimal user interface.

## Built With

- Kotlin
- Jetpack Compose
- Material 3
- Android Studio

## Future Plans

- Replace the button with pixel art.
- Add simple upgrades to increase points per click.
